HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. Replace the placeholder content and contact links with your final details.
4. Add photographs to assets/images/ and update the photo tile backgrounds in assets/css/style.css.
5. Upload the complete folder contents to your GitHub repository. Keep the folder structure unchanged.

GITHUB PAGES
In your GitHub repository, open Settings > Pages.
Choose Deploy from a branch, select the main branch and / (root), then Save.

NOTES
This is a complete static multi-page starter portfolio. It does not require a database, build tools or paid hosting.
